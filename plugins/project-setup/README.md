# project-setup

Skills for bootstrapping foundational project documentation and conventions. Each initializer works independently; `project-init` sequences the complete setup.

**Agents should read each skill's `SKILL.md`.** This README is the human-facing overview of the plugin.

## Skills in this plugin

| Skill | What it does |
|---|---|
| [`claude-agents-md-init`](skills/claude-agents-md-init/README.md) | Install aligned `CLAUDE.md` and `AGENTS.md` guidance from a shared template |
| [`git-strategy-init`](skills/git-strategy-init/README.md) | Install a worktree-based, multi-agent-safe git strategy |
| [`pitfalls-docs-init`](skills/pitfalls-docs-init/README.md) | Install implementation and testing pitfalls documentation |
| [`project-init`](skills/project-init/README.md) | Run the complete foundational setup in a clean sequence |
