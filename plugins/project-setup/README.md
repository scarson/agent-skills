# project-setup

Skills for bootstrapping foundational project guidance, Git policy, pitfalls documentation, Testing strategy, and Delivery strategy. Each initializer works independently; `project-init` sequences and reports the complete five-child setup.

**Agents should read each skill's `SKILL.md`.** This README is the human-facing overview of the plugin.

## Skills in this plugin

| Skill | What it does |
|---|---|
| [`claude-agents-md-init`](skills/claude-agents-md-init/README.md) | Install aligned `CLAUDE.md` and `AGENTS.md` guidance from a shared template |
| [`git-strategy-init`](skills/git-strategy-init/README.md) | Install a worktree-based, multi-agent-safe git strategy |
| [`pitfalls-docs-init`](skills/pitfalls-docs-init/README.md) | Install implementation and testing pitfalls documentation |
| [`testing-strategy-init`](skills/testing-strategy-init/README.md) | Create or adopt an evidence-bounded, progressively activated Testing strategy |
| [`delivery-strategy-init`](skills/delivery-strategy-init/README.md) | Create or adopt an evidence-bounded, progressively activated Delivery strategy |
| [`project-init`](skills/project-init/README.md) | Run all five initializers in order and report structured mixed outcomes |
