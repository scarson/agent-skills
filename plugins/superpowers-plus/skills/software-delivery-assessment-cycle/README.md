# Software Delivery Assessment Cycle

This skill validates claims from one closed software-delivery assessment and persists later evidence and decisions as a graph-linked addendum. It shares the assessment artifact contract and leaves closed root and addendum snapshots immutable.

For source provenance, licensing, and the product boundary, see the [software delivery assessment README](../software-delivery-assessment/README.md).

## Boundary

The cycle may write an explicitly authorized remediation plan. It does not implement remediation, create a scope-expanded assessment, or infer commit or push authority.
