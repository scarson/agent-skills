## Changes

The local capability model turns practice descriptions and dependency relationships into contextual assessment questions. The testing model reorganizes component-pattern and feedback guidance around material failure risk, trustworthy detection, boundary realism, and path enforcement. The agentic overlay adapts only the seven mapped pages into five conditional assessment domains.

The overlay makes three local generalizations rather than treating them as upstream requirements. It accepts agent-authored authority when an independently attributable governing decision or control adopts the artifact for its scope. It uses consequence-proportionate independent control instead of universal human review. It also applies the overlay when continuous-delivery foundations are absent so the assessment can expose the added risk from agent speed while reporting the foundation gaps through the core model.

Concepts learned from the broader corpus are not automatically labeled as copied expression. Only the three rows above define the adapted file scope.
