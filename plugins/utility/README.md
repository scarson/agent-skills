# utility

General-purpose skills that do not belong to a more specialized plugin.

**Agents should read each skill's `SKILL.md`.** This README is the human-facing overview of the plugin.

## Skills in this plugin

| Skill | What it does |
|---|---|
| [`url-to-markdown`](skills/url-to-markdown/README.md) | Transcribe a web article from a URL into a local Markdown file with YAML frontmatter |
| [`stop-slop`](skills/stop-slop/README.md) | Remove predictable AI writing patterns from prose — filler phrases, formulaic structures, passive voice, vague declaratives. **Vendored third-party work** by Hardik Pandya under MIT; see the skill's README for attribution and update procedure |
